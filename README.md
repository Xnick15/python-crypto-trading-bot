# Crypto Trading Bot

An automated cryptocurrency trading bot built with Python that scans Coinbase markets, identifies trade opportunities using technical indicators, and manages positions with configurable risk controls.

## Features

* Real-time Coinbase market data
* Automated trade execution
* Multi-timeframe analysis
* Adaptive scoring system
* Risk management and cooldown controls
* Discord trade alerts
* Performance tracking
* FastAPI monitoring interface

## Technologies Used

* Python
* FastAPI
* Coinbase Advanced API
* WebSockets
* REST APIs
* Discord Integration

## Project Highlights

This project demonstrates:

* API integration
* Automated trading logic
* State management
* Real-time data processing
* Risk management systems
* Backend development
